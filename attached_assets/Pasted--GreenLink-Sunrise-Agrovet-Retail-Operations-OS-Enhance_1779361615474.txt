2. Alias Match

→ product: Basagran 1L
→ confidence: 0.99

→ DAP Fertilizer 50KG

3. QUANTITY INFERENCE ENGINE (ENHANCED)
Purpose
Many shop books contain PRICE ONLY.

Example:

DAP 8400
No quantity written.

Inference Logic
Known DAP sell price = 2800
8400 ÷ 2800 = 3
→ infer qty = 3
Multi-Pattern Support
Pattern A — Price Only
DAP 8400
→ qty inferred from unit price
Pattern B — Explicit Quantity
DAP x3
DAP 3
DAP qty 3
Pattern C — Mixed Units
BASA 2pcs
UREA 4bags
Pattern D — Bulk Lines
DAP 16800
→ qty = 6
Smart Rounding Logic
8500 ÷ 2800 = 3.03
→ round to 3
→ confidence penalty applied
Confidence adjusted automatically.
