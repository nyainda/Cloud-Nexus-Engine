# Android Chrome Rasterization / Flickering / Scan-Line Fix Guide

Based on your POS code.  
Main issue is Android Chrome GPU compositor overload caused by:

- contain: paint
- opacity layers
- rounded clipping
- huge scrolling grids
- transition-all
- nested overflow-hidden
- fixed overlays

---

# 1. REMOVE contain: paint

## REMOVE THIS:

```tsx
style={{ contain: "paint" }}
```

## CHANGE FROM:

```tsx
<div className="flex-1 overflow-y-auto p-3" style={{ contain: "paint" }}>
```

## TO:

```tsx
<div className="flex-1 overflow-y-auto p-3">
```

---

# 2. REMOVE TRANSPARENT BACKGROUNDS

## CHANGE ALL THESE:

```tsx
bg-card/60      -> bg-card
bg-card/40      -> bg-card

bg-muted/30     -> bg-muted
bg-muted/40     -> bg-muted
bg-muted/50     -> bg-muted
bg-muted/60     -> bg-muted

border-border/40 -> border-border
border-border/50 -> border-border
border-border/60 -> border-border
border-border/80 -> border-border

bg-black/60 -> bg-black
```

---

# 3. REMOVE transition-all

## CHANGE:

```tsx
transition-all duration-300
```

## TO:

```tsx
transition-opacity duration-300
```

## OR:

```tsx
transition-transform duration-300
```

---

# 4. REDUCE ROUNDED CORNERS

## CHANGE:

```tsx
rounded-2xl -> rounded-xl
rounded-xl  -> rounded-lg
rounded-lg  -> rounded-md
```

---

# 5. REMOVE EXTRA overflow-hidden

## SEARCH FOR:

```tsx
overflow-hidden
```

## REMOVE IT FROM:

- product cards
- wrappers
- containers
- non animated sections

## KEEP ONLY WHERE REALLY NEEDED

---

# 6. REMOVE EXPENSIVE SHADOWS

## CHANGE:

```tsx
shadow-xl -> shadow-md
shadow-lg -> shadow-sm
```

## OR REMOVE COMPLETELY

---

# 7. FIX OVERLAY BACKDROPS

## CHANGE:

```tsx
<div className="absolute inset-0 bg-black/60" />
```

## TO:

```tsx
<div className="absolute inset-0 bg-black" />
```

---

# 8. ADD GPU STABILITY FIX

## ADD THIS TO MAIN PRODUCT GRID CONTAINER

```tsx
style={{
  transform: "translateZ(0)",
  backfaceVisibility: "hidden"
}}
```

---

# 9. PRODUCT CARD OPTIMIZATION

## CHANGE PRODUCT CARD FROM:

```tsx
className={cn(
  "relative flex flex-col text-left rounded-xl border p-3",
  ...
)}
```

## TO:

```tsx
className={cn(
  "relative flex flex-col text-left rounded-md border p-3",
  ...
)}
```

---

# 10. LOADING CARD FIX

## CHANGE:

```tsx
className="rounded-xl border border-border/40 bg-card/60 p-3 space-y-2"
```

## TO:

```tsx
className="rounded-md border border-border bg-card p-3 space-y-2"
```

---

# 11. MAIN PERFORMANCE FIX

## INSTALL:

npm install @tanstack/react-virtual

---

# 12. OPTIONAL CHROME ANDROID FIX

## ADD THIS TO BODY OR ROOT CONTAINER

```tsx
style={{
  WebkitTransform: "translate3d(0,0,0)"
}}
```

---

# 13. IMPORTANT

## AVOID THESE IN LARGE SCROLLING LISTS:

```tsx
opacity
backdrop-blur
contain: paint
transition-all
heavy shadows
nested overflow-hidden
large rounded corners
multiple fixed overlays
```

---

# MOST IMPORTANT 3 FIXES

## 1.

REMOVE:

```tsx
contain: paint
```

## 2.

REMOVE:

```tsx
all /40 /50 /60 opacity backgrounds
```

## 3.

REMOVE:

```tsx
transition-all
```

These 3 alone will probably fix the Android Chrome raster lines issue.
